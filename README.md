# faratalent-uptime

پایش بیرون از سرور برای محصولات فراتلنت (D-020 ِ نقشهٔ کل). هر ۵ دقیقه نشانی‌های سلامت از سرورهای گیت‌هاب چک می‌شوند؛ قطعی تازه اجرای `uptime` را شکست می‌دهد (ایمیل گیت‌هاب) و اگر `BALE_TOKEN` و `BALE_CHAT_ID` در Secrets باشند، قطع و وصل در بله هم خبر داده می‌شود.

عمومی است تا دقیقه‌های Actions رایگان باشد؛ هیچ رازی در این ریپو نیست.
